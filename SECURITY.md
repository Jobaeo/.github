# Security Policy

## Reporting a vulnerability

If you find a security issue in any Jobaeo product, please report it privately.
**Do not open a public issue or post it publicly.**

Email: security@jobaeo.com

Please include:
- A description of the issue and where you found it
- Steps to reproduce it
- The potential impact, if you know it

## What to expect

- We will acknowledge your report within 3 business days.
- We will keep you updated while we investigate and fix it.
- Please give us reasonable time to fix the issue before sharing it publicly.

## Out of scope

- Spam, social engineering or physical attacks
- Issues that need a rooted or jailbroken device
- Reports from automated scanners with no proof of impact
